# UI Components & Design Tokens Guide

---

## 1. Design Tokens & Palette

- **Primary Brand Color:** Deep Navy `#1e3a8a` (Primary buttons, headers, active tabs)
- **Secondary Accent:** Teal `#0f766e` (Secondary CTAs, badges)
- **Action Highlight:** Accent Blue `#2563eb` (Links, focus rings)
- **Background Neutral:** Light Slate `#f8fafc`
- **Card Background:** Pure White `#ffffff`
- **Text Color Primary:** Slate 900 `#0f172a`
- **Text Color Secondary:** Slate 600 `#475569`
- **Mandatory QCO Badge:** Red 600 `#dc2626`
- **Recommended Badge:** Green 600 `#16a34a`

---

## 2. Typography Scale

- **Page Title:** 32px / 36px line height (Bold, Inter)
- **Section Heading (H2):** 22px / 28px line height (Semi-bold, Primary Navy)
- **Subheading (H3):** 18px / 24px line height (Semi-bold, Slate 900)
- **Body Text:** 14px–16px / 22px line height (Regular, Slate 700)
- **Small Metadata:** 12px–13px / 16px line height (Medium, Slate 500)

---

## 3. Responsive Breakpoints

- **Desktop Extra Wide:** $\ge 1440\text{px}$
- **Desktop Standard:** $1280\text{px}$
- **Tablet Viewport:** $768\text{px}$–$1024\text{px}$
- **Mobile Viewport:** $\le 768\text{px}$ (Activates hamburger drawer nav)
